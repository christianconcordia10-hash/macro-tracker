# Macro Tracker (Gram-Based Meal Tracking)

A clean, modern, mobile-friendly macro tracking web app built with **HTML, CSS, and vanilla JavaScript**.

## Features

- Gram-based food entry (exact weighed amounts)
- Default protein goal pre-filled to **180g**
- Editable goals for calories, protein, carbs, and fat
- Meal sections with support for multiple foods per meal
- Automatic meal totals and full-day totals
- Progress bars for macro goals with protein highlighted
- Daily feedback for under/over goal status
- Edit/delete meals and foods
- Local persistence with `localStorage`

## Run locally

1. Download or clone this project.
2. Open a terminal in the project folder.
3. Start a local server:

   ```bash
   python3 -m http.server 8000
   ```

4. Open your browser to:

   ```
   http://localhost:8000
   ```

You can also open `index.html` directly, but using a local server is recommended.
